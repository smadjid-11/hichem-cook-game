# Hichem Cook 🍕

A fun and silly 2D game written in Python using Pygame.  
Play as Hichem the hungry cook and collect as many pizzas as you can!

## 🎮 Features
- Classic snake-style gameplay
- Custom visuals and Algerian-style sound effects
- Score tracking and game over screen

## 🧑‍💻 Requirements
- Python 3.x
- pygame library

## ▶️ How to Run
```bash
pip install pygame
python hichem_cook.py
